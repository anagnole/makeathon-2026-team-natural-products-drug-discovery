Never use the em-dash character (U+2014) when writing, anywhere. This includes code comments, file content, commit messages, PR descriptions, and conversational responses.

**Why:** Stated as a hard preference by the user.

**How to apply:** Use commas, periods, parentheses, or colons instead. Also avoid en-dash (–) where it might be confused for stylistic em-dash use.
