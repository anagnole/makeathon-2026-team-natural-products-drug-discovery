Carried over from the Echo hackathon (Oct 2026): the user called a long AI-written plan "70 pages of nonsense", asked for the API contract to be "very harshly simplified as this is only a hackathon", and said "in general we dont want many different big files, short and simple and few".

**Why:** two people and about five build days. Machinery wins no judging points.
**How to apply:** build the smallest thing that works; add detail to an existing doc instead of a new file; a page or two, not a spec. Related: [[feedback_prefer_simple]], [[feedback_open_choices]].
